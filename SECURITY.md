# Security policy

Please do not report credentials, tokens, customer data, or other sensitive material in
public issues. Report vulnerabilities through the repository's private GitHub Security
Advisory form:

https://github.com/OpenBearOrg/autotest-tool/security/advisories/new

If the form is unavailable, ask a repository administrator to enable private security
reporting before sharing details. Do not disclose sensitive material in a public issue.

Supported security fixes track the current development line and the latest released version.
The maintainer will acknowledge a private report, assess impact, and coordinate disclosure
after a fix or mitigation is available.
